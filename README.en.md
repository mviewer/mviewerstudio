# 🗺️ mviewerstudio

**mviewerstudio** is a web application for creating [mviewer](https://github.com/mviewer/mviewer) configurations through a simple graphical interface.

- **Frontend**: JavaScript
- **Backend**: Python + Flask
- **Platform**: Linux

---

## 🚀 Quick start with Docker Compose

```bash
# Source code
git clone https://github.com/mviewer/mviewerstudio.git
cd mviewerstudio
# Prepare permissions as described in docker/README.en.md before starting
# Docker
docker compose up -d
```

Open **http://localhost/mviewerstudio**.

See the [Docker guide](docker/README.en.md) to prepare permissions and configure UID/GID.

For detailed Flask or Docker instructions, see the [installation guide](install/README.en.md).
